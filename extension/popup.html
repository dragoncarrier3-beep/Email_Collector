📨 Automatic sending (Gmail API)
For one-click auto-send, set up a free Google OAuth client once:
1. Enable the Gmail API in a Google Cloud project.
2. Configure the OAuth consent screen (External, add yourself as a test user).
3. Create Credentials → OAuth client ID → Chrome Extension, and paste this extension's ID (from chrome://extensions).
4. Copy the client ID into manifest.json → oauth2.client_id, then reload.
Until then, Send falls back to opening Gmail for a one-click send.
⚠ Staying out of spam
No tool can guarantee inbox placement — the recipient's provider decides. To stay out of spam: keep volume low (this app sends only 3 / 2 days), each person gets a separate email, an opt-out line is added automatically, and you should only email people your message is genuinely relevant to. If recipients mark you as spam, future mail gets filtered — so relevance matters most.
